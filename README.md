# Personal Portfolio - Putri Hayyufi Sa'adah
### Tema Desain: Dusty Pink Luxury

Website Personal Portfolio modern, elegan, dan profesional untuk **Putri Hayyufi Sa'adah**, mahasiswa aktif Program Studi **Bisnis Digital**, Fakultas Ilmu Komputer, **Universitas Lancang Kuning**.

---

## 🎨 Konsep & Palet Warna (Dusty Pink Luxury)

- **Dusty Pink**: `#D8A7AD` (Aksen Utama / Primary Accent)
- **Soft Pink**: `#EBCBD0` (Elemen Halus & Border)
- **Blush Pink**: `#F6E8E8` (Highlight & Latar Belakang Lembut)
- **Cream White**: `#FFF9F8` (Latar Belakang Dasar Bersih & Mewah)
- **Rose Brown**: `#79565D` (Tombol Utama, Header & Teks Kontras)
- **Muted Rose**: `#BC858E` (Aksen Pendukung & Gradient)

---

## 🚀 Fitur Utama

1. **Sticky Glassmorphism Navbar**: Menu navigasi responsif dengan active-section indicator dan mobile drawer menu.
2. **Hero Section**: 
   - Heading resmi *"Hi, I'm Putri Hayyufi Sa'adah"*
   - Subjudul *"Digital Business Student"*
   - Deskripsi perkenalan lengkap
   - Tombol **Explore My Portfolio** & **Download CV** (dengan modal cetak/simpan PDF)
   - Tautan sosial media (Instagram, LinkedIn, WhatsApp).
3. **About Me**: Foto profil berdampingan dengan narasi kepribadian profesional, status akademis, dan kartu ringkasan minat.
4. **Education Timeline**: Jejak pendidikan di Universitas Lancang Kuning, Fakultas Ilmu Komputer, Bisnis Digital (Status: Mahasiswa Aktif).
5. **My Skills**: 8 keterampilan utama dengan kartu elegan, level penguasaan, daftar tools, dan animated progress bar yang persentasenya dapat disesuaikan.
6. **Work & Creative Experience**: Pengalaman dalam lingkup creative agency, manajemen media sosial, pembuatan konten digital, dan editing desain konten dengan kartu profesional.
7. **My Projects Gallery**: Galeri portofolio filterable (Semua, Social Media, Graphic Design, Canva Design, Video Editing, Digital Business) dilengkapi tombol **View Project** dan modal detail interaktif.
8. **Certificates & Achievements**: Galeri sertifikasi dan pencapaian dengan modal pratinjau sertifikat beresolusi penuh tanpa data palsu.
9. **Interactive Contact Form**: Formulir kontak interaktif dengan validasi pesan, toast feedback berhasil, serta opsi pengiriman langsung ke WhatsApp.
10. **Footer**: Menyertakan *"Designed with creativity by Putri Hayyufi Sa'adah"*, quick links, tautan sosial, dan tombol kembali ke atas (*Back to Top*).

## ✏️ Cara Mengubah Data Portofolio

Cukup buka berkas:
👉 **`src/data/portfolioData.js`**

Anda dapat langsung mengganti:
- Nomor WhatsApp & Akun Instagram Anda
- Foto profil (ganti URL atau letakkan foto di folder `public/`)
- Persentase atau level kemampuan
- Detail pengalaman & nama agency/organisasi
- Foto dan deskripsi proyek asli
- Foto sertifikat dan nama penyelenggara asli

---

## 🛠️ Perintah Menjalankan Aplikasi

- Menjalankan server pengembangan:
  ```bash
  npm run dev
  ```
  Buka peramban di: `http://localhost:5173`

- Membuat build produksi:
  ```bash
  npm run build
  ```
